# خروجی‌های ویندوز

نصب‌کنندهٔ ویندوز با `npm run dist` در پوشهٔ `amookht-windows/dist` ساخته می‌شود:

```
Amookht-Setup-<version>.exe
Amookht-Setup-<version>.exe.blockmap
latest.yml
```

این فایل‌ها به‌دلیل حجم (حدود ۸۰ مگابایت) در گیت نگه داشته نمی‌شوند. محل انتشار:

- دانلود مستقیم: `https://learn.tah3in.com/downloads/Amookht-Setup-<version>.exe`
- feed به‌روزرسانی خودکار: `https://learn.tah3in.com/downloads/latest.yml`

روش ساخت و انتشار: [`docs/windows/build-and-update.md`](../../docs/windows/build-and-update.md).

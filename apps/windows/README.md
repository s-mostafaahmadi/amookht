# Amookht for Windows (v3)

برنامهٔ ویندوزی آموخت — **همهٔ بخش‌ها و گزینه‌های `learn.tah3in.com`** (به‌جز صفحهٔ نخست/ورود سایت)
در یک قاب ویندوزی واقعی: عنوان‌بار سفارشی، نوار کناری به ترتیب خود سایت، جستجو و فرمان‌ها با `Ctrl+K`،
نوار وضعیت، سینی سیستم و ویجت رومیزی.

## ساختار

- **قاب ویندوزی (`src/app.*`)**: ورود بومی؛ پس از ورود، خود برنامهٔ سایت (موتور واقعی، نه بازسازی) در یک
  `<webview>` باز می‌شود. نوار کناری و داک موبایل سایت پنهان می‌شوند و قاب جای آن‌ها را می‌گیرد.
- **بخش‌ها (به ترتیب سایت)**: اجرای برنامه، دفتر عبارات، علاقه‌مندی‌ها، کتابخانه (PRO)، مربی گفتگو (PRO)،
  شبیه‌سازی آزمون (PRO)، تاریخچه، تنظیمات برنامه، مدیریت (فقط مدیر/مالک)، و تنظیمات حساب از کارت حساب.
  هر چیزی که داخل این صفحه‌هاست (مطالعهٔ آزاد، ربات گرامر، مترجم، نوار انتخاب متن، رنگ‌بندی جمله‌ها، …) همان نسخهٔ سایت است.
- **هماهنگی دوطرفه**: حالت تیره/روشن، رنگ اصلی (۵ رنگ سایت)، زبان (فارسی/English/Deutsch) و «سایدبار فشرده»
  هم از سایت و هم از قاب (فرمان‌ها، دکمه‌های عنوان‌بار، پنجرهٔ تنظیمات ویندوز) تغییر می‌کنند و همه‌جا یکی می‌مانند.
- **حس نرم‌افزار، نه مرورگر**: پنجره بار اول بزرگ (maximized) باز می‌شود؛ اگر جا برای چیدمان دسکتاپ سایت کم باشد
  نوار کناری خودکار آیکونی می‌شود؛ اسکرول‌بار باریک ویندوز ۱۱ فقط با hover؛ بدون کشیدن لینک/تصویر و بدون overscroll؛
  منوی راست‌کلیک بومی (کپی/چسباندن/املا)؛ Ctrl+چرخ موس = بزرگ‌نمایی برنامه.

## میان‌برها

| کلید | کار |
| --- | --- |
| `Ctrl+K` | جستجوی بخش‌ها و فرمان‌ها (رنگ، زبان، تراکم، شیشه، کنتراست، بزرگ‌نمایی، ویجت، خروج…) |
| `Ctrl+1…9` | رفتن به بخش‌ها |
| `Alt+←` / `Alt+→` | بازگشت / جلو |
| `F5` / `Ctrl+Shift+R` | بازخوانی / بازخوانی کامل |
| `Ctrl+B` | جمع/باز کردن نوار کناری |
| `Ctrl+=` `Ctrl+-` `Ctrl+0` | بزرگ‌نمایی |
| `Ctrl+,` | تنظیمات ویندوز |
| `Ctrl+Alt+W` / `Ctrl+Alt+A` | ویجت / نمایش برنامه |

## ویجت رومیزی

پنل جمع‌وجور سرمه‌ای با دو زبانهٔ **کارها** و **یادداشت‌ها** (همان `/v1/widget/data` حساب): افزودن (+)، تیک زدن،
حذف (×)، سنجاق «همیشه رو»، بازخوانی، و «خروج از حساب» در پایین. اندازه با کشیدن لبه‌ها تغییر می‌کند و ذخیره می‌شود.
ویجت همیشه به همان حسابی وصل است که برنامهٔ ویندوز با آن وارد شده.

## قفل سایت (/_gate)

تا وقتی قفل پروژه‌های Tah3in روشن است، برنامه روی هر درخواست به سایت هدر `X-Amookht-App-Token` (توکن حساب واردشده)
می‌فرستد و `gate.js` فقط برای `learn.tah3in.com` (مسیر `/_gate/check-learn`) آن را با `/v1/account/me` می‌سنجد.
وقتی قفل خاموش یا از nginx برداشته شود، این هدر نادیده گرفته می‌شود و هیچ کاری لازم نیست.

## ساخت و اجرا

```bash
npm install
npm start                 # اجرای برنامه
npm start -- --hidden     # فقط سینی/ویجت
npm run dist              # ساخت نصب‌کننده → dist/Amookht-Setup-3.0.0.exe
```

## تست‌ها

```bash
npx electron test/app-smoke.js        # قاب: ورود، نوار کناری، هماهنگی با سایت، Ctrl+K، جمع شدن خودکار
npx electron test/smoke.js            # ویجت: لیست، افزودن/تیک/حذف، یادداشت‌ها، تغییر اندازه
npx electron test/settings-smoke.js   # پنجرهٔ تنظیمات
npx electron test/app-boot.js --user-data-dir="%TEMP%/amk-boot-test"   # main process، منو، ویجت
npx electron test/live-check.js --user-data-dir="<کپی پوشهٔ %APPDATA%\Amookht>"   # روی سایت واقعی با حساب واردشده
```

## فایل‌ها

```
electron/main.js             پنجره‌ها، webview امن سایت، توکن و هدر قفل، میان‌برها، منوی راست‌کلیک، سینی، ویجت، IPC
electron/preload-app.js      پل قاب
electron/preload-site.js     تزریق نشست به سایت (tokens + tdf_session + active tab) و پل پیام‌ها
electron/preload-widget.js   پل ویجت
electron/preload-settings.js پل تنظیمات
src/app.html|css|js          قاب ویندوزی + کمک‌کنندهٔ تزریقی سایت (siteHelper)
src/widget.*                 ویجت رومیزی
src/settings.*               پنجرهٔ تنظیمات ویندوز
```

## داده‌ها

- نشست، تنظیمات و اندازهٔ پنجره‌ها: `%APPDATA%\Amookht\state.json` (توکن‌ها با `safeStorage` ویندوز رمز می‌شوند).
- خروج از حساب در سایت، قاب یا ویجت، از هر سه خارج می‌کند. حذف موقت توکن توسط سایت (مثلاً هنگام ری‌استارت سرور) خروج حساب نمی‌شود.

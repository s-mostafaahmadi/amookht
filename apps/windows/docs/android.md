# نسخهٔ اندروید

نسخهٔ اندروید آموخت همان محصول وب است که در یک قاب بومی (WebView + PWA) بسته‌بندی می‌شود؛ بنابراین
با هر به‌روزرسانی فرانت، اپ هم به‌روز می‌شود و فقط تغییرات بومی نیاز به APK تازه دارند.

## مشخصات

| مورد | مقدار |
| --- | --- |
| بسته | `com.amookht.app` (نسخهٔ منتشرشده: 1.4) |
| حداقل اندروید | 8.0 (API 26) |
| صفحهٔ میزبان | `/mobile.html` و `/android.html` روی همان دامنه |
| مانیفست | `/android.webmanifest` (آیکون، رنگ تم، `display: standalone`) |
| نشست | همان JWT؛ ورود در WebView، نگهداری با `localStorage` امن‌شدهٔ وب‌ویو |
| صدا | ضبط با `MediaRecorder` و ارسال به `/v1/speaking/...` |
| آفلاین | سرویس‌ورکر صفحهٔ پوسته + کش محتوا؛ تمرین‌ها بدون شبکه اجرا می‌شوند، همگام‌سازی بعداً |

## نکات انتشار

- امضای APK با کلید انتشار؛ نسخهٔ debug فقط برای تست.
- برای هر تغییر بومی: `versionCode` را بالا ببرید و APK را در Downloads سرور/ریپو بگذارید.
- مسیر `mobile.html` باید با نسخهٔ وب سازگار بماند؛ تغییر ساختار `S` می‌تواند اپ قدیمی را بشکند، پس
  قرارداد sync در سطح مسیر حفظ می‌شود.

## ساخت (خارج از این ریپو)

سورس اندروید جدا نگهداری می‌شود (پروژهٔ Android Studio با WebView). خروجی نهایی:
`Amookht-Android-<version>.apk`. دستورهای ساخت در README همان پروژه است.

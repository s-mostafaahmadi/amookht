# آموخت برای ویندوز — مستندات

اپلیکیشن دسکتاپ آموخت (Electron 32، نسخهٔ ۴.۱.۰) یک قاب ویندوزی کامل روی همان محصول وب است: همان حساب،
همان داده، همان موتور یادگیری — با نوار عنوان بومی، نوار کناری، جستجوی فرمان (`Ctrl+K`)، سینی سیستم،
ویجت رومیزی و یک **موتور بومی (Native)** که بخش‌های اصلی را بدون webview بازسازی می‌کند.

## دو حالت اجرا

| حالت | توضیح |
| --- | --- |
| **بومی (پیش‌فرض)** | صفحه‌های پورت‌شده (`src/native/*`): اجرای برنامه، دفتر اشتباهات، علاقه‌مندی‌ها، کتابخانه، شبیه‌ساز آزمون، تاریخچه، تنظیمات، مدیریت. سریع‌تر، آفلاین‌پذیرتر، هم‌شکل با ویندوز |
| **سایت (webview)** | همان `learn.tah3in.com` داخل قاب؛ برای هر چیزی که هنوز بومی نشده |

سوئیچ: `--native` / `--site` یا در تنظیمات برنامه (`engine`). پیش‌فرض بومی است.

## نصب و اجرا

```powershell
# نصب از فایل نصب‌کننده
Amookht-Setup-4.1.0.exe            # نصب برای کاربر جاری (بدون نیاز به ادمین)

# اجرا
& "$env:LOCALAPPDATA\Programs\Amookht\Amookht.exe"
& "$env:LOCALAPPDATA\Programs\Amookht\Amookht.exe" --hidden    # فقط سینی/ویجت
```

- اجرای خودکار در شروع ویندوز: کلید `HKCU\...\Run\electron.app.Amookht` با آرگومان `--hidden`.
- دادهٔ محلی: `%APPDATA%\Amookht\state.json` (نشست، تنظیمات، اندازهٔ پنجره‌ها؛ توکن‌ها با `safeStorage` رمز می‌شوند).

## میان‌برها

| کلید | کار |
| --- | --- |
| `Ctrl+K` | جستجوی صفحه‌ها و فرمان‌ها |
| `Ctrl+1…9` | رفتن به صفحه‌ها به ترتیب نوار کناری |
| `Alt+←` / `Alt+→` | بازگشت / جلو |
| `Ctrl+B` | جمع/باز کردن نوار کناری |
| `Ctrl+=` `Ctrl+-` `Ctrl+0` | بزرگ‌نمایی |
| `Ctrl+,` | تنظیمات ویندوز |
| `Ctrl+Alt+W` / `Ctrl+Alt+A` | ویجت / نمایش برنامه |
| `F5` / `Ctrl+Shift+R` | بازخوانی / بازخوانی کامل |

## صفحه‌ها (به ترتیب سایت)

1. **اجرای برنامه** — برنامهٔ روزانهٔ شش‌دسته‌ای، برنامهٔ هفته، ترتیب امروز، تمرکز هفته، پیشرفت روز
2. **دفتر اشتباهات** — اشتباهات دستی و خودکار، مرور SRS
3. **علاقه‌مندی‌ها** — سؤال‌های نشان‌شده
4. **کتابخانه** (PRO) — منابع و PDF
5. **مربی گفتگو** (PRO)
6. **شبیه‌ساز آزمون** (PRO)
7. **تاریخچه** — روزها، امتیازها، فایل روز (مالک)
8. **تنظیمات برنامه** — تم، رنگ، زبان، تراکم، موتور
9. **مدیریت** (مدیر/مالک)
10. **حساب** — پروفایل، سطح، تاریخ آزمون، خروج
